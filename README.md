# Early Disease Prediction Using Machine Learning

## Project Overview

This project explores machine learning techniques for predicting potential disease categories using health-related symptoms and data. It includes a trained model, symptom-related resources, and visualizations for model evaluation and analysis.

## Features

* Machine learning-based prediction
* Trained model and label encoder
* Symptom list for prediction inputs
* Confusion matrix visualization
* Symptom frequency analysis
* Symptom co-occurrence analysis
* SHAP global feature-importance visualization
* Model robustness analysis

## Technology Stack

* Python
* Machine Learning
* Scikit-learn
* Data Analysis
* Data Visualization
* Explainable AI (SHAP)

## Repository Structure

* `best_model.joblib` — trained model
* `label_encoder.joblib` — label encoder
* `dataset_splits.npz` — prepared dataset splits
* `symptom_list.json` — symptom list
* `confusion_matrix.png` — model evaluation visualization
* `symptom_frequency.png` — symptom frequency visualization
* `symptom_cooccurrence.png` — symptom co-occurrence visualization
* `shap_global_importance.png` — global feature-importance visualization
* `robustness_curve.png` — robustness visualization

## How to Use

The trained model and supporting files are available in this repository. To run the complete application, the original Python source code and its required dependencies must also be available.

## Disclaimer

This is an educational machine learning project. Predictions are not medical diagnoses and must not be used as a substitute for professional medical advice.
